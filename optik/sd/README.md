# 🔦 Cahaya & Cermin! — Simulasi Optik & Cahaya (Jenjang SD)

Simulasi fisika interaktif bergaya PhET untuk siswa **Sekolah Dasar (Kelas 4-6)**, topik **Pemantulan Cahaya & Bayangan pada Cermin Datar**. Bagian **1 dari 3** dari topik Optik & Cahaya.

## 📁 Isi Folder

```
sd/
├── index.html                          # Simulasi interaktif
└── worksheet/
    └── LKS-Optik-Cahaya-SD.docx        # Lembar Kerja Siswa
```

## 🎯 Tentang Simulasi Ini

Ada dua percobaan dalam satu simulasi:
1. **Pemantulan Cahaya** — siswa mengatur sudut datang cahaya senter ke cermin datar dan mengamati bahwa sudut pantul selalu sama besar (Hukum Pemantulan Cahaya).
2. **Bayangan di Cermin** — siswa mengatur jarak benda (huruf "R") ke cermin dan mengamati bahwa bayangan terbentuk pada jarak yang sama, berukuran sama, tetapi terbalik kiri-kanan.

## 🧑‍🏫 Cara Menggunakan di Kelas
Bagikan simulasi dan LKS (`worksheet/LKS-Optik-Cahaya-SD.docx`). Alur: prediksi → coba di simulasi → catat hasil pada dua tabel pengamatan → diskusi kelas. Estimasi waktu: 30–40 menit.
