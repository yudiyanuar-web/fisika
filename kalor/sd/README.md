## 🎯 Tentang Simulasi Ini

Meniru percobaan klasik "batang logam dengan tetesan lilin": siswa memilih bahan batang (Tembaga, Aluminium, Besi, Kaca, atau Kayu), menyalakan api di salah satu ujung, dan mengamati seberapa cepat titik-titik lilin di sepanjang batang meleleh. Semakin cepat meleleh, semakin baik bahan tersebut menghantarkan panas (konduktor); jika tidak sempat meleleh, bahan tersebut adalah isolator panas.

**Konsep yang dilatih:** perpindahan panas secara konduksi, serta pengelompokan bahan menjadi konduktor dan isolator panas — murni lewat pengamatan visual, tanpa rumus.

## 🧑‍🏫 Cara Menggunakan di Kelas
