# 🌡️ Lab Kalor & Suhu — Simulasi Kalor & Perpindahan Panas (Jenjang SMP)

Simulasi fisika interaktif bergaya PhET untuk siswa **SMP (Kelas 7)**, topik **Kalor, Kalor Jenis, Kalor Laten, dan Perubahan Wujud**. Bagian **2 dari 3** dari topik Kalor & Perpindahan Panas.

## 📁 Isi Folder

```
smp/
├── index.html                # Simulasi interaktif
└── worksheet/
    └── LKS-Kalor-SMP.docx    # Lembar Kerja Siswa
```

## 🎯 Tentang Simulasi Ini

Simulasi menampilkan **grafik pemanasan klasik** (grafik suhu terhadap waktu) saat 1 kg es dipanaskan dari -10°C hingga menjadi uap 120°C, melewati lima tahap: es memanas → melebur → air memanas → mendidih → uap memanas. Siswa dapat menggeser slider waktu (atau menekan "Putar Otomatis") untuk melihat proses berlangsung secara live, lengkap dengan termometer, ikon wujud zat, dan kotak perhitungan yang merinci kalor dan waktu tiap tahap.

**Konsep yang dilatih:** Q = m·c·ΔT, Q = m·L (kalor laten), dan pembacaan grafik pemanasan — sesuai materi Kalor kelas 7 SMP.

## 🧑‍🏫 Cara Menggunakan di Kelas
Bagikan simulasi dan LKS (`worksheet/LKS-Kalor-SMP.docx`). Alur yang disarankan: siswa mengamati grafik pada daya bawaan (1000 W), mencatat lama waktu tiap tahap, lalu membandingkan dengan daya 2000 W untuk melihat pengaruh daya terhadap waktu, baru mengerjakan soal perhitungan. Estimasi waktu: 40–45 menit.
